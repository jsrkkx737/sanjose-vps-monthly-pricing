## 常见问题

**月付套餐能用优惠码吗？**

可以试，但不能保证。上面提到的几个码都来自第三方整理，官方页面没有确认过。结算页填进去看实际折扣，能减就减。循环码通常对所有计费周期生效，首单码只对第一次购买有效。

**600GB 双向流量够不够？**

双向计费意味着上传和下载都算。每天 20GB 的额度，跑一个日均几百 PV 的博客、做 SSH 和轻量 API 转发，用不完。真正吃流量的是视频、大文件下载、持续中转，这类用途直接看 B1 的 1.5TB，或者考虑不限流量系列。

**不是原生 IP 会影响什么？**

影响两类场景：需要 IP 归属地真实性的注册和风控，以及部分对机房 IP 段敏感的服务。日常建站、代理、开发测试不受影响。流媒体方面商家提供了 DNS 解锁方案，实测能不能用，一个月付试出来最准。

**不满意能退吗？**

不能。VPS 产品不支持退款，这是明确的政策。所以不确定就先买月付，一个月的钱换一次真实验证，比年付赌一年稳。
